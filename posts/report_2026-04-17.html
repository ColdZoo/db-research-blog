1. gMatch: Fine-Grained and Hardware-Efficient Subgraph Matching on GPUs

  • **Authors:** Weitian Chen, Shixuan Sun, Cheng Chen, Yongmin Hu, Yingqian Hu, Minyi Guo
  • **Venue:** arXiv (submitted to SIGMOD/VLDB)
  • **Link:** https://arxiv.org/abs/2604.10601

    • Abstract: Subgraph matching is a core operation in graph analytics supporting applications from social network analysis to bioinformatics. Recent GPU-based methods leverage parallelism but suffer from coarse-grained execution models with high memory overhead and poor thread utilization. This paper proposes gMatch, a hardware-efficient subgraph matching method on GPUs.

    Key Contributions:

  • Introduces **fine-grained execution model** reducing memory consumption and enabling flexible task scheduling among threads
  • Designs **warp-level batch exploration** and **lightweight load balancing** for improved execution efficiency and scalability
  • Outperforms state-of-the-art methods (STMatch, T-DFS, EGSM) in both performance and scalability
  • Scales to larger queries and datasets where existing methods degrade or fail

    • Performance Improvements:

  • Superior performance vs. STMatch, T-DFS, and EGSM
  • Better scalability compared to BEEP and G²Miner on large datasets
  • 17 pages, 17 figures, 2,336 KB
