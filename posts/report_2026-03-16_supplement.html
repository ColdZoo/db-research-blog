🏷️ Data Encoding / Decoding + GPU Acceleration

1. ZipFlow: a Compiler-based Framework to Unleash Compressed Data Movement for Modern GPUs

  • **arXiv**: 2602.08190 (2026年2月)
  • **Authors**: Gwangoo Yeo, Zhiyang Shen, Wei Cui, Matteo Interlandi, Rathijit Sen, Bailu Ding, Qi Chen, Minsoo Rhu
  • **PDF**: [arXiv PDF](https://arxiv.org/pdf/2602.08190)

    • Key Contributions:

  • 编译器驱动的端到端优化框架，平衡 I/O 延迟和计算开销
  • 将压缩算法按并行性分为三种模式，为每种模式设计通用调度策略
  • 解决 CPU-GPU 数据传输瓶颈问题
  • **Performance**:

    • - 比 nvCOMP 提升 2.08x

    - 比 DuckDB 快 3.14x (TPC-H)

    Relevance: ⭐⭐⭐⭐⭐ High - 编译器优化 + 压缩数据移动 + GPU

    2. G-ALP: Rethinking Light-weight Encodings for GPUs

  • **Conference**: DaMoN 2025 (Workshop)
  • **Authors**: Sven Hepkema, Azim Afroozeh, Peter Boncz, Thomas Neumann
  • **Link**: [ACM DL](https://dl.acm.org/doi/10.1145/3736227.3736242) | [GitHub](https://github.com/cwida/FastLanesGpu-Damon2025)

    • Key Contributions:

  • 面向 GPU 的轻量级浮点数据编码方案
  • 为 OLAP 工作负载设计
  • 在压缩比和解压吞吐量之间取得最佳平衡
  • **Achievement**: Highest compression ratio AND highest decompression throughput among all encoding schemes

    • Relevance: ⭐⭐⭐⭐⭐ High - 轻量级编码 + GPU 优化

    3. A High-Throughput GPU Framework for Adaptive Lossless Compression of Floating-Point Data

  • **arXiv**: 2511.04140 (2025年11月)
  • **Authors**: Zheng Li (重庆大学) 等，包括 OceanBase, Ant Group 合作者
  • **PDF**: [arXiv PDF](https://arxiv.org/pdf/2511.04140)

    • Key Contributions:

  • 面向 IoT 和 HPC 浮点数据的 GPU 自适应无损压缩框架
  • 三项关键创新：

    • 1. 轻量级异步流水线，隐藏 CPU-GPU 传输延迟

    2. 快速且理论保证的无误差浮点-整数转换

    3. 自适应稀疏位平面编码，处理异常值稀疏性

  • **Performance** (12个数据集平均):

    • - 压缩比: 0.299 (提升 9.1%)

    - 压缩吞吐量: 10.82 GB/s (提升 2.4x)

    - 解压吞吐量: 12.32 GB/s (提升 2.4x)

    Relevance: ⭐⭐⭐⭐⭐ High - 浮点压缩 + GPU 加速
