    • 2. Data Encoding & Compression Papers

    2.1 CLAD: Log Anomaly Detection on Compressed Data

  • **Authors:** Benzhao Tang, Shiyu Yang
  • **Source:** arXiv:2604.13024 [cs.LG], April 2026
  • **Key Contributions:**

    • - First deep learning framework for log anomaly detection directly on compressed byte streams

    - Key insight: normal logs exhibit regular byte patterns after compression; anomalies disrupt these patterns

    - Architecture: dilated convolutional byte encoder + hybrid Transformer-mLSTM + 4-way aggregation pooling

    - Two-stage training: masked pre-training + focal-contrastive fine-tuning

  • **Performance:**

    • - 0.9909 average F1 score (SOTA)

    - 2.72 percentage points above best baseline

    - Zero decompression overhead

  • **Link:** https://arxiv.org/abs/2604.13024

    Key Observations

    1. GPU-Native Compression Formats Emerging: L3 (SIGMOD'26) represents a new class of GPU-native compression formats that co-design compression algorithms with GPU execution patterns.

    2. Query-on-Compressed Becoming Standard: Multiple papers (GPU SQL on Compressed, CLAD) demonstrate direct query processing on compressed data without decompression, eliminating I/O bottlenecks.

    3. Vector Search GPU Acceleration: SIGMOD 2026 features 5+ papers on GPU-accelerated vector search (FlashANNS, VecFlow-Chamfer, CMANNS, etc.), reflecting the importance of ANNS in modern RAG systems.

    4. LLM-Database Integration Deepening: CoDec (SIGMOD'26) and several other papers show increasing focus on database-system perspectives on LLM serving and optimization.

    5. FineZip Impact: Despite being from 2024, FineZip continues to be referenced as a key milestone for practical LLM-based compression, demonstrating 54× speedup over prior approaches.
